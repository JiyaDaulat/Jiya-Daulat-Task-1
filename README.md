Cyber Security Internship – Task 1
Basic Network Scanning using Nmap

Description
This repository contains my work for the cybersecurity internship task focused on network scanning using Nmap. The objective was to perform a TCP SYN scan on the local network, identify active hosts, discover open ports, and analyze potential risks.

Tools Used
Nmap (free, official build)

Task Performed
Conducted a TCP SYN scan on the local network (192.168.1.0/24).

Saved the scan output in results.txt.
Analyzed open ports and services running on discovered hosts.
Identified potential risks associated with exposed services.

Output:
result.txt - Output file generated from the Nmap Scan
result.png -  Screenshot showing SYN packets filteres in Nmap
